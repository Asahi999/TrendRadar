# 微信群发

在 Android 手机上，用无障碍服务操作已经安装的微信（包名 `com.tencent.mm`），把一段文字发给通讯录里的好友单聊。

备注或显示名命中排除词的好友不发。默认排除含有 `😈`、`👿`、`小恶魔` 的显示名。排除词可以自己增删。

只有你点「开始」，并在名单上点「确认发送」之后，才会逐个打开聊天。没有后台静默群发，也不导出通讯录。

本目录是仓库里的 Android 工程。许可证与仓库根目录的 `LICENSE` 相同。

## 环境

- Android SDK，已安装 `platforms;android-35` 和 `build-tools;35.0.0`
- JDK 17 或更高
- 环境变量 `ANDROID_HOME` 指向 SDK，或在本目录写 `local.properties`：

```
sdk.dir=/你的/android-sdk
```

## 编译

在仓库根目录：

```bash
./gradlew assembleDebug
```

或进入本目录：

```bash
cd wechat-broadcast
./gradlew testDebugUnitTest assembleDebug
```

debug APK：

```text
wechat-broadcast/app/build/outputs/apk/debug/app-debug.apk
```

这是 debug 签名，用来侧载，不是上架包。单元测试覆盖排除规则：命中、不命中、空规则、emoji、前后空白。

## 安装

把 APK 拷到手机后安装。用数据线时：

```bash
adb install -r wechat-broadcast/app/build/outputs/apk/debug/app-debug.apk
```

如果系统拦截侧载应用的无障碍权限：

1. 打开系统设置 → 应用 → 微信群发 → 允许受限设置（不同品牌的名字可能略有差别）。
2. 再去无障碍里打开本应用的服务。

## 打开无障碍

1. 安装并打开「微信群发」。
2. 主界面会显示无障碍和微信是否就绪。
3. 点「打开无障碍设置」，在系统列表里找到「微信群发」并开启。
4. 服务说明里写了它会做什么：确认名单之后，才操作微信界面。
5. 回到应用。状态变为「无障碍：已开启」后再点开始。

微信需要事先从正规渠道安装并登录。包名必须是 `com.tencent.mm`。

## 怎么设排除词

1. 主界面点「编辑排除词」。
2. 默认有三项：`😈`、`👿`、`小恶魔`。显示名里只要包含其中任意一项，就不会进入待发送名单。
3. 在底部输入新词后点「添加」，点「删除」去掉某一条。
4. 「恢复默认」只改当前列表，点「保存」后才写回本机。
5. 可以删光所有排除词再保存。这样没有人会因为排除词被跳过，但仍然要确认名单后才发送。
6. 匹配时忽略文案和词两端的空白，不忽略中间的空格。「小 恶魔」和「小恶魔」不是同一个词。英文字母不区分大小写。

分组标题和功能入口不参与排除计数，直接跳过，例如：新的朋友、群聊、标签、公众号、服务号、企业微信联系人，以及单个字母索引。单个汉字姓名会保留。

## 发送

1. 写下这次的文案。空文案不能开始。
2. 发送间隔默认 5 秒，可改成 3 到 60 秒。这段等待是为了让聊天窗口打开、发出、再返回，不是用来躲避平台限制的随机延迟。
3. 点「开始」。应用会打开微信并滚动通讯录，只读取屏幕上的显示名。
4. 读完后回到确认页，看清将发送多少人、排除多少人，以及两边的名字。
5. 点「确认发送」才开始逐个打开单聊。点「返回修改」或系统返回，则这次不发。
6. 进行中可以暂停、继续或停止。停止后不再处理后面的人，并给出成功、失败和排除的汇总。

同一轮里，同一个显示名只保留一次，避免列表滚动时重复发送。

## 风险与局限

- 微信可能把短时间连续发送视为异常，从而限制功能或封号。你亲自确认也不能消除这个风险。
- 微信界面会随版本变化。按钮文字或列表结构一变，读取名单或点击发送就会失败。失败会记在结果里。本应用不会改走协议、hook 或注入。
- 无障碍是敏感权限。服务开启后保持空闲，直到你在本应用里发起任务。没有定时发送，也没有隐藏自动化的开关。
- 备注如果正好等于「群聊」「公众号」这类入口原文，会被当成入口跳过。只有一个英文字母或 `#` 的显示名会当成索引跳过。
- 搜索时如果分不清同名的好友和群，这一条会跳过并记失败，不会随便点第一项。
- 不读取系统通讯录，不生成联系人文件，不上传名单。确认页上的名字只留在这次任务的内存里。

## 真机才能验证有没有发出去

debug 包可以装进模拟器，用来看主界面、排除词和确认页。模拟器未必装得上微信，装上了也未必能登录。

真正有没有把消息发进好友单聊，必须在已经安装并登录微信的 Android 真机上，走完「开始 → 确认名单 → 发送」之后，到微信里查看。自动化没点到「发送」时，结果页会记失败，不能把它当成已经发出。
